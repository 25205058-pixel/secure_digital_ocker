# Secure Digital Locker System

A C++ OOP-based secure credential management system with:

- User Registration/Login
- 2FA Authentication
- Password Encryption/Decryption
- Record Management
- Web/Mobile/Desktop Records
- Admin Module
- Backup & Restore
- Multi-user Support
- File Handling
- Security Alerts

## Concepts Used
- Inheritance
- Polymorphism
- Encapsulation
- Abstraction
- File Handling
- Exception Handling
- STL
